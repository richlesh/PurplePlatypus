## Emoji Sampler

A test set of emoji across different Unicode ranges.

These emoji live in the U+0000–U+FFFF range.

|-------|------|
| ☀️ | Sun |
| ☂️ | Umbrella |
| ★ | Black Star |
| ☎️ | Telephone |
| ✂️ | Scissors |
| ✈️ | Airplane |
| ✉️ | Envelope |
| ✏️ | Pencil |
| ❤️ | Red Heart |
| ⚽ | Soccer Ball |
